# Как запустить бота на Render — с телефона, бесплатно, 24/7

Render — это облачный хостинг. Бот будет работать на сервере Render круглосуточно,
даже когда твой телефон и компьютер выключены. Бесплатного тарифа хватает.

Нужно сделать это **один раз**, дальше всё работает само.

---

## Шаг 1. GitHub — туда нужно положить код бота (≈5 минут)

1. Открой в браузере телефона **github.com**. Если аккаунта нет — зарегистрируйся
   (Sign up, почта + пароль).
2. Нажми значок **«+»** (справа вверху) → **New repository**.
3. Название: `fragment-nft-bot`. Обязательно выбери **Private** (закрытый).
   Внизу нажми **Create repository**.
4. Теперь загрузи файлы бота. Сначала распакуй архив `fragment-nft-bot.zip`
   на телефоне (нажми на архив в «Файлах» / менеджере файлов → «Извлечь»).
5. В репозитории нажми **Add file → Upload files** → **choose your files** →
   выдели **все файлы** из папки (bot.py, tg.py, parser.py, resolver.py, db.py,
   config.py, keep_alive.py, requirements.txt, render.yaml, README.md) →
   внизу зелёная кнопка **Commit changes**.

> Если телефон не даёт выбрать файлы — в браузере открой меню (⋮) и включи
> **«Версия для ПК» / «Полная версия сайта»**, затем повтори шаг 5.

---

## Шаг 2. Render — сам хостинг (≈5 минут)

1. Открой **render.com** → кнопка **Get Started** → **Sign up with GitHub**
   (войти через GitHub-аккаунт из шага 1). Разреши доступ к репозиториям.
2. Нажми **New +** (справа вверху) → **Blueprint**.
3. Выбери репозиторий `fragment-nft-bot` → нажми **Connect** → **Apply**.
4. Render спросит два значения (он сам покажет поля):
   - **BOT_TOKEN** — вставь токен бота (строка вида `9076024497:AAGx...`,
     та же, что в @BotFather);
   - **OWNER_ID** — твой Telegram ID (число). Если не знаешь его — оставь
     пустым, потом допишешь: запусти бота, нажми /start — внизу сообщения
     будет «🆔 Твой ID».
5. Нажми **Apply** и подожди 3–5 минут, пока идёт сборка.
   Статус сервиса должен стать зелёным — **Live**.

Всё! Бот работает на сервере круглосуточно. Открой его в Telegram и нажми /start.

---

## Проверка и мелочи

- **Логи**: render.com → твой сервис → вкладка **Events/Logs** — там видно,
  что делает бот («Бот запущен: @parsbotnft_bot», «self-ping 200»).
- **Перезапуск**: render.com → сервис → **Manual Deploy → Deploy latest commit**.
- **Изменить токен/OWNER_ID**: render.com → сервис → **Environment** →
  измени значение → **Save** (сервис сам перезапустится).

## Важно знать (бесплатный тариф)

1. **На Windows бота больше не запускай.** Два работающих бота одновременно
   конфликтуют (Telegram отдаёт ошибку 409). Работать должен только один —
   на Render.
2. **Подписки могут сбрасываться.** Бесплатный Render хранит базу во временной
   памяти: после перезапуска сервиса подписки и лимит цены слетают. Бот сам
   напишет тебе об этом в Telegram (если указан OWNER_ID) — тогда просто
   заново выбери категории через /cats. Обычно это случается редко.
3. **Бот сам себя «будит»** каждые 10 минут, поэтому бесплатный Render его
   не усыпляет — в логах это видно как `self-ping 200`.

Если что-то пошло не так — пришли скрин экрана Render или текст ошибки.
