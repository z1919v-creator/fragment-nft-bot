# 🦊 Fragment NFT Watch — Telegram-бот

Мониторит лоты NFT-подарков Telegram на **fragment.com** и присылает в Telegram
**только тех продавцов, которым можно написать** — у каждого есть @username и
кнопка «Написать продавцу» с готовым текстом оффера.

## Что умеет

- 📦 **Выбор категорий** — все 120+ коллекций Fragment (Plush Pepe, Snoop Cigar,
  Loot Bag…), с поиском по названию. Поиск остаётся активным: запросы можно
  вводить один за другим, ничего отменять не нужно
- 🆕 **Авто-обновление по дате выставления** — как только продавец выставляет
  подарок, бот присылает лот (проверка раз в 60 сек по умолчанию)
- 👤 **Только продавцы с @username** — бот определяет кошелёк продавца и через
  TON API проверяет, владеет ли он юзернеймом (все @username Telegram — NFT).
  Лоты продавцов без юзернейма не присылаются: им всё равно нельзя написать
- 💰 **Цена-максимум** — «слать только до N TON»: уведомления только по лотам
  не дороже лимита (настройка ⚙️ → 💰 или команда /price)
- 📉 **Снижения цены** — если продавец подешевил лот, придёт уведомление
  «было / стало / −экономия» (не чаще раза в 30 минут на лот)
- 📊 **Статистика** — «сегодня выставлено N лотов» по каждой подписке
  (кнопка 📊 или /stats)
- 🎭 В сообщении: фото, цена, атрибуты подарка (Model / Backdrop / Symbol
  с редкостью), @username, кнопки «Написать продавцу» / «Лот» / «Кошелёк»

## 🚀 Гайд: как запустить

> 💡 **Про ошибку `failed-wheel-build-for-install` (aiohttp / pydantic-core):**
> она была в старой версии архива, которая зависела от aiogram. В этой версии
> aiogram и его компилируемые зависимости **убраны полностью** — остались
> только `httpx` и `aiosqlite` (чистый Python). Они ставятся на любой Python
> 3.10+ (включая самый свежий) под Windows **без Visual Studio и без
> компиляции**. Просто распакуй этот архив поверх старого и повтори шаги 2–4.

> ⚠️ **Если бот пишет `certificate verify failed` / `Hostname mismatch`** —
> твоя сеть блокирует или подменяет fragment.com (DPI провайдера, DNS-подмена
> или антивирус). При этом сам Telegram работает — блокируется именно Fragment.
> Решения — в разделе «Если fragment.com недоступен» ниже.

### Самый простой способ (Windows)

Распакуй архив и запусти **`start.bat`** двойным кликом: он сам создаст
окружение, поставит зависимости, спросит прокси (можно просто нажать Enter)
и запустит бота.

### Ручная установка

### Шаг 1. Установи Python 3.10+

- **Windows**: скачай с https://www.python.org/downloads/ → при установке
  отметь галочку **"Add Python to PATH"** → проверь: `python --version`
  (подойдёт и самый свежий Python — компилировать ничего не придётся)
- **Linux/Mac**: обычно уже есть; иначе `apt install python3 python3-venv`
  (Ubuntu/Debian) или `brew install python`

### Шаг 2. Распакуй архив и создай окружение

Открой терминал в папке с ботом:

```bash
cd fragment-nft-bot

python -m venv venv
```

Активируй окружение:

```bash
# Windows (PowerShell):
venv\Scripts\Activate.ps1
# Windows (cmd):
venv\Scripts\activate.bat
# Linux/Mac:
source venv/bin/activate
```

После активации в начале строки появится `(venv)`.

### Шаг 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4. Запусти бота

```bash
python bot.py
```

В консоли появится: `Бот запущен: @parsbotnft_bot`.

### Шаг 5. Открой бота в Telegram

Найди **@parsbotnft_bot** → **Start**. Токен уже вписан в `config.py`.

**Первое сообщение:** жми «📦 Категории» → выбери коллекцию (или «🔍 Поиск»
и просто пиши `pepe`, `snoop`, `loot`…) → подпишись.

**Важно про первый опрос:** при подписке бот молча запоминает текущие лоты
(до 60 шт.) — историей не спамит. Дальше присылает только новые, поэтому
первые уведомления придут, когда кто-то реально выставит новый лот. Чтобы
не ждать — нажми «🆕 Лоты сейчас» сразу после подписки.

### Как держать бота включённым

Самый удобный способ — **бесплатный хостинг Render**: бот работает 24/7
на сервере, телефон и компьютер можно выключить. Инструкция для телефона —
в файле **RENDER.md** (коротко: github.com → загрузить файлы → render.com →
New + → Blueprint → вставить BOT_TOKEN → всё).

Локально:

- **Windows, просто дома**: оставь окно терминала открытым. Неудобно —
  запусти через `pythonw bot.py` (окно не нужно) или установи pywin32 и
  оформи автозапуск через Планировщик заданий.
- **Linux VPS / Mac — способ «на час»**: `screen -S bot` → запусти →
  `Ctrl+A, D` — отключился от сессии, бот работает. Вернуться: `screen -r bot`.
- **Linux VPS — навсегда (systemd)**, файл `/etc/systemd/system/fragment-bot.service`:

```ini
[Unit]
Description=Fragment NFT Watch bot
After=network-online.target

[Service]
WorkingDirectory=/opt/fragment-nft-bot
ExecStart=/opt/fragment-nft-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Потом: `sudo systemctl enable --now fragment-bot` — бот будет запускаться
сам, даже после перезагрузки сервера. Логи: `journalctl -u fragment-bot -f`.

| 🔍 Поиск | вводи слова подряд — поиск активен, отмена не нужна |
| «🆕 Лоты сейчас» | свежие лоты с продавцами-@username |

| `/price` / ⚙️ → 💰 | цена-максимум в TON (0 — снять лимит) |
| `/stats` / «📊 Статистика» | «сегодня выставлено N» по каждой подписке |
| `/diag` / ⚙️ → 🩺 | диагностика сети: что доступно, что блокируется |
| `/now` / «🆕 Проверить сейчас» | внеплановая проверка всех подписок |
| `/stopall` | отписаться от всего |

## Как это работает

1. **Каталог.** Fragment отдаёт каталог серверным HTML:
   `/gifts/<коллекция>?sort=listed&filter=sale` — активные лоты, новые сверху.
   Бот забирает первую страницу (60 лотов) каждый цикл (60 сек).
2. **Детект нового лота.** ID лота (`plushpepe-69`) кладётся в SQLite. Первый
   прогон помечается как «история» (is_backfill) и не портит статистику
   «сегодня». Дальше всё новое — с уведомлением.
3. **Продавец.** Со страницы лота берётся TON-кошелёк; через публичный
   tonapi.io проверяется, владеет ли кошелёк NFT из коллекции
   «Telegram Usernames» → так узнаётся @username. **Нет @username — лот не
   присылается** (написать такому продавцу всё равно нельзя). Результаты
   кешируются, «пустые» кошельки перепроверяются раз в 7 дней.
4. **Снижение цены.** Если цена лота в каталоге стала ниже запомненной —
   уведомление 📉 со старой/новой ценой. Не чаще раза в 30 минут на лот.
5. **Лимит цены.** У каждого юзера свой лимит (price_max): уведомления
   приходят только по лотам не дороже. Настраивается в /price.

## Важно знать

- **Не у всех продавцов есть @username** — у флипперов-оптовиков часто только
  кошелёк. Такие лоты фильтруются — это сделано специально. Если по коллекции
  долго тихо, проверь «🆕 Лоты сейчас»: возможно, там просто нет продавцов
  с юзернеймом.
- tonapi.io без API-ключа ограничен ~1 запрос/сек — бот соблюдает интервал.
  Хочешь быстрее — получи ключ на tonconsole.com, впиши в `resolver.py`
  (заголовок `Authorization: Bearer <ключ>`) и уменьши `TONAPI_MIN_INTERVAL`.
- Fragment иногда меняет вёрстку. Если лоты перестали приходить — смотри
  лог в консоли (ошибки парсинга/сети видны сразу).
- **Токен бота** лежит в `config.py` — не публикуй его и не коммить в git.
  Засветил — отзови у @BotFather (`/revoke`). Переменные окружения `BOT_TOKEN`,
  `POLL_SECONDS`, `PRICE_DROP_COOLDOWN` переопределяют значения конфига.

## Настройки (`config.py`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `POLL_SECONDS` | 60 | период проверки новых лотов |
| `OWNER_ID` | 0 | твой Telegram ID: бот напишет, если хостинг его перезапустит |
| `SELF_PING_SECONDS` | 600 | как часто бот будит себя на Render (чтобы не уснул) |
| `PEEK_COUNT` | 5 | сколько лотов показывать по «Лоты сейчас» |
| `PEEK_SCAN_LIMIT` | 12 | сколько лотов просматривать в поисках @username |
| `PRICE_DROP_COOLDOWN` | 1800 | кулдаун уведомлений о снижении (сек) |
| `PROXY` | — | прокси для всех запросов, напр. `http://127.0.0.1:7890` или `socks5://127.0.0.1:1080` |
| `SSL_VERIFY` | True | False — не проверять SSL-сертификаты (если антивирус перехватывает HTTPS) |
| `OFFER_TEXT` | см. файл | шаблон оффера; подстановки `{item}` и `{price}` |
| `WALLET_RECHECK_DAYS` | 7 | перепроверка кошельков без @username |

## Если fragment.com недоступен (SSL-ошибки, «Hostname mismatch»)

Если в консоли повторяется `категории не получены: [SSL: CERTIFICATE_VERIFY_FAILED]
... Hostname mismatch ... 'fragment.com'` — значит, между ботом и fragment.com
кто-то вклинивается и подсовывает чужой сертификат. Причины и что делать,
в порядке частоты:

1. **Блокировка/DPI провайдера.** Браузер может открывать fragment.com через
   VPN-расширение или DoH, а Python ходит напрямую. → включи VPN в системном
   режиме (TUN / «прокси для всех приложений») и перезапусти бота.
2. **Нужен прокси.** Если у VPN-клиента есть локальный прокси-порт — запусти
   `start.bat` и введи адрес (например `http://127.0.0.1:7890` или
   `socks5://127.0.0.1:1080`), либо впиши `PROXY = "..."` в `config.py`,
   либо задай переменную `HTTPS_PROXY` перед запуском.
3. **DNS-подмена.** Проверь файл `C:\Windows\System32\drivers\etc\hosts` —
   если там есть строка с `fragment.com`, удали её (файл правится от
   администратора). Затем `ipconfig /flushdns`.
4. **Антивирус перехватывает HTTPS** (Kaspersky и др.). → добавь Python и
   бота в исключения, либо поставь в `config.py` `SSL_VERIFY = False`.

Проверить, что именно недоступно: **⚙️ Настройки → 🩺 Диагностика сети**
(или `/diag`) — бот проверит fragment.com, nft.fragment.com, tonapi.io и
api.telegram.org и покажет статус каждого.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `SSL: CERTIFICATE_VERIFY_FAILED`, `Hostname mismatch` для fragment.com | сеть блокирует/подменяет fragment.com — см. раздел «Если fragment.com недоступен» выше |
| `failed-wheel-build` для aiohttp / pydantic-core | старый архив с aiogram — скачай этот новый и повтори `pip install -r requirements.txt` в свежем venv |
| `No module named 'aiogram'` | новый архиву aiogram не нужен — запускаешь новый `bot.py` из старого venv; пересоздай venv (шаг 2) |
| `pip install` падает (иное) | нет интернета / старый pip → `python -m pip install --upgrade pip` |
| `python bot.py` → `Conflict: terminated by other getUpdates` (или 409) | бот уже запущен в другом месте (второе окно, другой сервер) — оставить нужно один; на Render он продолжит сам |
| Логи на Render: `self-ping 200` — что это | всё хорошо: бот сам себя будит, чтобы бесплатный тариф не усыпил его |
| Не пишет в Telegram (таймауты) | api.telegram.org недоступен из сети — включи VPN или задай прокси (start.bat спросит сам) |
| Лоты не приходят | 1) «🆕 Проверить сейчас» 2) ⚙️ → 🩺 Диагностика сети 3) возможно, у продавцов нет @username |
| Пусто в «Лоты сейчас» | в коллекции нет продавцов с @username в топе — попробуй другую |
